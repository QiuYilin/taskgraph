# 界面说明

`Ui::Run()` 打开一套 VS Code 风格的工作台，两个后端共用 core 与 `ui/model`。界面字符串用英文。本文先写 **ImGui 版**（默认后端），再写 **Qt 版**。

工程是目录：`project.json`、`graphs/`、`assets/`。工程内路径存相对路径；会话在用户配置目录的 `taskgraph/session.json`。`simple-ui` 与 `simple-qt` 都把源码里的 `demo-project` 复制到可执行文件旁再打开，改图不会弄脏仓库。

一个工程可以有多张 graph。节点属于创建它的那张 graph。种类要先 `registerNodeType`，编辑区里的新建、打开工程和粘贴都走这份登记；界面名默认去掉 type id 末尾的 `Node`，显式 caption 原样使用。怎么建工程、怎么 `run`，见仓库根目录的 README。

# ImGui 版

分区从外到内是：标题栏、活动栏、主侧栏、编辑区、辅助侧栏、面板、状态栏。主题是 **Dark Modern** 或 **Light Modern**，色值来自随仓库附带的 VS Code 官方主题 JSON。

```text
┌──────────────────────────────────────────────────────────────┐
│ 标题栏   File  Run  Help          工程名           — □ ×   │
├────┬────────────┬────────────────────────────┬──────────────┤
│活动│ 主侧栏     │ 编辑区                      │ 辅助侧栏     │
│栏  │ Explorer   │ 页签                        │ Properties   │
│    │            │ 画布 / Welcome / 快捷键     │              │
│    │            ├────────────────────────────┤              │
│    │            │ 面板  Output                │              │
├────┴────────────┴────────────────────────────┴──────────────┤
│ 状态栏   工程名   Run   当前图                    选中节点   │
└──────────────────────────────────────────────────────────────┘
```

活动栏在主侧栏左边。主侧栏、编辑区、辅助侧栏、面板停在活动栏右边、状态栏上面。标题栏和状态栏通栏。活动栏和状态栏不进停靠，每帧按矩形摆放。停靠区第一次按整窗宽度的 2/12 给主侧栏，辅助侧栏在右侧，面板占编辑列高度的 1/4。拖过之后以停靠布局为准。

## 标题栏

从左到右三块：菜单栏、命令中心、窗口按钮。菜单栏里没有活动栏，也没有第二条工具栏。

菜单栏从左到右是 **File**、**Run**、**Help**。

- **File**：New Project...、Open Project...、Open Recent、Save、Save As...。**Preferences > Theme** 在 Dark Modern 与 Light Modern 之间切换，立刻生效，并写入用户配置目录的 `taskgraph/session.json`。**Preferences > Keyboard Shortcuts** 在编辑区打开快捷键页签。
- **Run**：**Run Graph** 跑当前 graph。没有 graph 时这项不可用。
- **Help**：**Welcome** 打开 Welcome 页签。

命令中心只显示工程名。没有工程时显示 **Untitled**。点击没有动作。

窗口按钮从左到右是最小化、最大化或还原、关闭。空白处拖动可移动窗口；铺满工作区时不拖。双击空白处在铺满和还原之间切换。

系统窗口标题是 `工程名[*] - 应用名`。工程有未保存改动时，工程名后多一个 `*`。没有工程时只显示应用名。当前应用名是 **Default Ui**。

工程名还出现在另外三处：命令中心、主侧栏 Explorer 的树根、状态栏左侧。

## 活动栏

贴在标题栏下面、状态栏上面，宽 48×界面缩放。图标 24×界面缩放，放在格子正中。从上到下是 **Explorer** 和 **Search**。悬停显示这两项的名字。

点图标切换主侧栏里的视图。当前项左侧有一条竖线。再点当前图标不收起主侧栏。

## 主侧栏

窗口标题随视图变化：**EXPLORER** 或 **SEARCH**。

### Explorer

有工程时，树根是工程名。鼠标悬停在这一行时，右侧出现 **+ Node** 和 **+ Graph**。这两个按钮不在窗口标题上。

**+ Node** 打开种类列表，只进入落点，不创建节点。没有 graph 时这个按钮不可用。**+ Graph** 新建一张空 graph，并立刻就地命名；不打开编辑区页签。

每张 graph 占一行，下面只列出用这张 graph 创建的节点。还没有节点时，这一行仍然留着，下面是空的。点图名左边的箭头只展开或收起。点图名会清掉节点选中，并在编辑区打开这张图的页签。

图的右键菜单：**New Node**、**Rename**、**Delete**。节点的右键菜单同样是这三项。**New Node** 的落点规则和 **+ Node** 相同。

主侧栏有焦点、并且不在改文字时：**F2** 有选中节点就改该节点名，否则改当前图名；**Delete** 或 **Backspace** 有选中节点就删节点，否则删当前图。同一张图里节点 identifier 必须唯一，重名会被拒绝，不会自动加后缀。

没有打开工程时，这里显示 **NO PROJECT OPENED**、**Open Project...**，以及最近打开过的工程。

### Search

替换 Explorer 那棵树。上面是过滤框，下面列出图名，以及 `图名 / 节点 identifier`。只匹配能看见的图名和节点 identifier，不匹配 kind。没有命中时显示 **No matching results**。点一条结果会打开对应的 graph 页签；点到节点时同时选中它。

## 编辑区

启动后如果没有可恢复的页签，这里打开 **Welcome**。**Welcome** 里是 **Start**（New Project...、Open Project...）和 **Recent**。从菜单打开工程时不自动打开 graph 页签；下次启动会按会话恢复上次打开的 graph 页签。

页签从左到右排在编辑区顶部，可以点掉关闭。关掉页签不删除 graph。全部关掉之后不显示画布，中间提示 **No editor is open**，并说明从 Explorer 打开 graph，或用 **+ Graph** 新建。

页签有三种：

- **Welcome**
- **Keyboard Shortcuts**：过滤框在上，下面三列是 Command、Keybinding、When。这一页只列出快捷键，不能在这里改键。
- graph：页签名是图名。这一页的右侧、与页签同一行，有 **Show Type Names**。打开后，引脚功能名上方叠类型名，节点 identifier 上方补一行 kind。类型名用类型色，引脚仍和功能名对齐。

graph 页签下面是画布。节点第一次出现时，工程里有坐标就用那个坐标，否则按列排开。之后的位置写回工程。针脚默认画成圆，颜色由类型 id 哈希；作者可在 `NodeData_` 上可选指定 `PinShape` / `PortTypeColor`。

选中种类之后，编辑区里跟着指针走的是种类名，最后一个字的右下角贴着指针。这还不是节点，主侧栏里也没有这一行。下一次在编辑区按下左键，才在该点创建节点。**Esc** 或画布右键取消，不创建。

画布上的操作：

- 左键点选节点或连线。选中连线时，主侧栏的选中不变，主侧栏里也没有连线这一行。
- 从引脚拖到另一个引脚来连线。同一个输入不接受第二根入边，会成环的边也会被拒绝。类型不一致的连线用错误色。
- 右键拖动平移，滚轮缩放。拖节点时按住 **Alt** 关闭网格吸附。
- **Alt+点击** 删掉一根连线。选中连线后按 **Delete** 也删这一根，不删整张图。

右键菜单：

- 输入引脚：**Convert to Property**。
- 节点：**Cut**、**Copy**、**Duplicate**、**Delete**、**New Node**。
- 空白处：**Paste**、**New Node**。剪贴板为空时 **Paste** 不可用。

**Ctrl+C** 复制选中节点，以及这些节点之间的连线。只选中连线时不复制。**Ctrl+X** 剪切这些节点。**Ctrl+V** 贴到指针处。**Ctrl+D** 按小偏移再复制一份。剪贴板只留在当前进程里，换工程或重置工程时清掉。macOS 上这些 Ctrl 组合键是 Command。

**F** 框住选中、指针下的节点或整张图。**Shift+F** 带边距框住。正在落点时，剪切、复制、粘贴、原位复制、空格新建，以及 **F**、**Shift+F**、**Delete** 不响应。

## 辅助侧栏

这里是 **Properties**。

选中节点时，表有三列：**Name**、**Type**、**Value**。原生属性可以直接改。整数是 `int`，布尔是勾选框，字符串可以手输，也可以 **Browse** 选文件。图像和点云的值是导入文件的路径。

有固定输入口时，每个输入槽默认以端口露面：画布上有引脚，属性表仍列出这一行，但只读。右键 **Convert to Property** 后，画布不再画这只引脚，属性表可以改；指向该口的入边会断开，口上的上游数据清空。右键 **Convert to Port** 改回端口露面。属性露面时，不能再把线连到这个口。节点一开始就没有固定输入口时，没有这套切换，只有原生属性。

选中连线时，表改成两列：**Type**、**Value**。这是这根线代表的变量。变量目前没有名称。输出已经算出、并且能写成属性值时，**Value** 里有值。

## 面板

状态栏上面、编辑区下面是面板。默认只有 **Output**，按行显示日志。有新行时滚到末尾；没有新行时保留当前滚动位置。

## 状态栏

通栏贴在最下面。从左到右是：工程名（有工程时）、**Run**、当前图名。点 **Run** 跑当前 graph，没有 graph 时不可用。点图名弹出列表，用来切换当前图，并在编辑区打开它。右侧是选中节点的 identifier；没选节点时右侧是空的。

## 快捷键

编辑区有焦点、并且不在落点时：

| 命令 | 键 |
| --- | --- |
| Cut | Ctrl+X |
| Copy | Ctrl+C |
| Paste | Ctrl+V |
| Duplicate | Ctrl+D |
| New Node | Space |
| Frame | F |
| Frame with Margin | Shift+F |
| Delete | Delete |
| Delete Wire | Alt+点击 |
| Pan | 右键拖动 |
| Zoom | 滚轮 |

拖动节点时，**Alt** 关闭网格吸附。主侧栏有焦点、并且不在改文字时，**F2** 改名，**Delete** 或 **Backspace** 删除节点或当前图。正在落点时，**Esc** 或右键取消。

完整列表和每条的 When 以编辑区的 **Keyboard Shortcuts** 页为准。

## 坐标系

工作台有三套坐标，嵌套方式和 Qt 的父窗口、子窗口相同。每一套都是左上角为原点，x 向右，y 向下。子区域自己的 `(0, 0)` 在它的左上角；这个点在父区域里另有一个位置。

`s` 是界面缩放（`ImGuiStyle::FontScaleMain`）。设计像素先乘 `s`，再拿去排窗口。

### 屏幕坐标

原点是主视口工作区的左上角。标题栏、活动栏、状态栏和停靠宿主都用这套坐标。

```text
                     x
                     →
          (0,0) ┌──────────────────────────────────────────┐
                │ 标题栏                              30×s │
             y  ├──────┬────────┬──────────────┬───────────┤
             ↓  │活动栏│ 主侧栏 │ 编辑区        │ 辅助侧栏  │
                │ 48×s │        │ (xe, ye)     │           │
                │      │        │ ┌画布 (0, 0) │           │
                │      │        ├──────────────┤           │
                │      │        │ 面板         │           │
                ├──────┴────────┴──────────────┴───────────┤
                │ 状态栏                              22×s │
                └──────────────────────────────────────────┘
```

| 区域 | 屏幕位置 | 尺寸 |
| --- | --- | --- |
| 标题栏 | 工作区顶边 | 高 30×`s` |
| 活动栏 | 标题栏下、状态栏上，贴左 | 宽 48×`s` |
| 状态栏 | 工作区底边，通栏 | 高 22×`s` |
| 停靠宿主 | 活动栏右边、状态栏上面 | 剩下的矩形 |

`(xe, ye)` 是编辑区里、页签栏下面那块节点编辑器的左上角。编辑区窗口自己的左上角还含着页签栏，比 `(xe, ye)` 更靠上。

### 画布坐标

节点在工程里的 `position` 是画布坐标。`simple-ui` 模板里第一颗 IntNode 是 `(120, 80)`，第二颗是 `(120, 220)`，AddNode 是 `(420, 140)`。

画布可以平移和缩放。换成屏幕坐标：

```text
屏幕点 = 画布点 × 视图缩放 + 视图原点 + (xe, ye)
```

缩放为 1、视图原点为 `(0, 0)` 时，屏幕点就是画布点再加上 `(xe, ye)`。所以上面那颗 IntNode 的屏幕位置是 `(xe + 120, ye + 80)`。

刚打开时视图原点是 `(0, 0)`、缩放是 1，正的节点坐标在编辑区内容里。

画布 `Begin` 期间，鼠标位置已经是画布坐标，落点直接用它。`Suspend` 之后鼠标回到屏幕坐标，要换回画布再使用。落点预览画在屏幕上。

### 节点坐标

节点原点是节点矩形的左上角。工程里的 `position` 就是这个角在画布上的位置。矩形从原点向右、向下长。

```text
                     x
                     →
          (0, 0) ┌──────────────────────────┐
          画布    │ 8×s                      │
       (120, 80) │   ┌ IntNode              │
              y  │   │                      │
              ↓  │   │                  out ○│
          屏幕    └──────────────────────────┘
    (xe+120, ye+80)
```

标题从原点再往里 8×`s` 才开始，四边留白相同。引脚在标题下面，连线用引脚中心。

# Qt 版

用 `TASKGRAPH_UI=qt` 构建。`Ui` 是 `QMainWindow`，`QApplication` 和事件循环由程序自己持有（`simple-qt` 是范例）。界面用 Qt 6 控件、Qt-Advanced-Docking-System 停靠和 QtNodes 画布。

## 外壳

标题栏是系统窗口标题 `工程名 - taskgraph`。中间是编辑区页签；主侧栏停左边，Properties 停右边，Output 停在编辑区下面。停靠可拖动、浮出、关闭；启动布局是主侧栏占 2/12、Output 占编辑区列高度的 1/4。

主侧栏最左边是活动栏：从上到下 **Explorer**、**Search**；再点当前图标不收起侧栏。Explorer 显示图和节点的树；Search 按图名和节点 identifier 过滤，点结果打开对应图（命中节点时同时选中它）。**View > Activity Bar** 隐藏/显示活动栏。

## 菜单

- **File**：New Project...、Open Project...、Open Recent、Save、Save As...；**Preferences > Keyboard Shortcuts** 打开只读快捷键页签；**Preferences > Theme** 在 **Dark Modern** / **Light Modern** 间即时切换，选择写入 `session.json`，下次启动恢复。
- **Edit**：Undo、Redo、Cut、Copy、Paste、Duplicate、Delete，作用于当前画布。
- **View**：Zoom In、Zoom Out、Fit All、Fit Selected；**Activity Bar**、**Explorer**、**Search**；**Properties** / **Output** 开关右侧属性表和底部面板。
- **Run**：**Run Graph**（F5）跑当前页签的图。
- **Help**：**Welcome**（暂不可用）。

## 主侧栏

树根是工程名，下面是图和节点。工程名行右侧：**+ Node**（有打开的图页签时可用）进入落点，**+ Graph** 新建空图。

右键菜单：图行 **New Node** / **Rename** / **Delete Graph**，节点行 **New Node** / **Rename** / **Delete Node**，工程根行 **New Graph**。**F2** 或双击在原处改名；空名和同图重名会被拒绝，状态栏提示原因。**Delete** / **Backspace** 删除选中的节点或图。

点图名打开页签；点节点选中它。

## 编辑区

每张打开的图一个页签；关页签不删图。快捷键页签是只读列表，和 imgui 版共用清单，但只列 Qt 实际绑定的命令，另加 Undo/Redo 两行。

选中种类后进入落点：下一次在画布左键才创建节点。**Esc** 或画布右键取消；没有落点时，画布空白处右键打开种类列表。

画布操作：拖动节点写回坐标；从引脚拖到另一个引脚连线；**Delete** / **Backspace** 删除选中的节点或连线；**View** 菜单里缩放、适配全部、适配选中。节点右键 **Delete Node**。

**Ctrl+Z** 撤销、**Ctrl+Y** 重做画布上的创建/删除/移动/连线/粘贴；**Ctrl+C** / **Ctrl+V** / **Ctrl+D** 复制、粘贴、原位复制选中的节点，**Ctrl+X** 剪切（复制后删除）。macOS 上 Ctrl 换成 Command。剪贴板是 QtNodes 的场景 JSON，能跨页签粘贴；同图粘贴撞名时保留入图自动名。属性表、Explorer 改名和主侧栏删除目前不进撤销栈。

## 属性表

选中节点时三列：**Name**、**Type**、**Value**。int 用数字框，bool 用勾选框，string 可直接输入；路径值右键 **Browse...** 选文件。端口露面的输入行只读；右键 **Convert to Property**，改回时用 **Convert to Port**。

## 面板与状态栏

**Output** 只读，按行追加 core 日志。状态栏从左到右：工程名、**Run**、当前图名、运行提示；右侧是选中节点的 identifier。没有图时 **Run** 不可用。

## 还没做

属性表与 Explorer 改名的撤销、选中连线时属性表显示变量、**Space** 打开种类列表、**F / Shift+F** 框选、启动恢复打开的页签、切工程时提示未保存、QtNodes 节点配色跟随主题。
